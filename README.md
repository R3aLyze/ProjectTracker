# ProjectTracker
Project Tracker Application Coded using Java that is similar to Trello

## Project Feature Plans
1. Add Project
2. Remove Project
3. Add Task
4. Remove Task
5. Mark Project as Complete
6. Mark Task as Complete
7. Edit Project
8. Edit Task
9. View Project Details
10. List All Projects
11. Sort tasks by priority or due date
12. Sort Project List by Alphabetical or Date
13. Allow User to Edit Tasks or Project
14. Store Data into a Database
